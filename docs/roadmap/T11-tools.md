# T11 — Tools (`tools/*`)

Tools multiply every other track: **`meta-dump` (T11-002) is the single most valuable early tool** — it
turns opaque `CTSEMETA` files into readable text so RE and loader work can move in parallel.

- [x] **T11-001** · `gro-tool`: `list`, `extract`, `cat`, `find` (glob/regex), `stats`, `diff` between archive sets; honors mount order · `M` · `P0` · 🟢 · Deps: T02-001
- [x] **T11-002** · `meta-dump` (`docs/META_DUMP.md`): prints any CTSEMETA file as annotated text, JSON or RON (header, chunks, type table, references, decoded objects, every region with its byte offset and size, `--raw` bytes) with a coverage report; `--unknown` lists the byte ranges no decoder explained; a file or `--install DIR` through the VFS; never panics on damaged input. **Not done** (T11-002b): the RON output is checked only against the repository's own parser, not the `ron` crate; objects after a record that fails to decode are one undecoded range (no resynchronization); "explained" counts raw byte arrays (about 75% of the install's bytes) as explained although their meaning is unknown; values use the file's member numbers, not game field names; no recovery of tables from a half-readable frame · `M` · `P0` · Deps: T02-006
